# XLPJ 失踪事件

## 该游戏目前为半成品，上传仅用于测试，请静候完结

从 `index.html` 开始，登录成功后进入 `second.html` 桌面。请通过静态 HTTP 服务访问，聊天、搜索和空间的数据使用 fetch 读取 JSON，不能直接双击 HTML 游玩。

## 桌面与存档

- 桌面包含 QQ、文件夹、search 三个入口，单击即可打开。文件夹内有 photofolder 和多个空文件夹；点击上方 ↑ 或“文件夹”路径可返回列表。
- QQ 和相册各自只保留一层窗口，点击窗口右上角的 × 返回桌面；搜索也提供 ×。底部任务栏可随时切换应用。
- 应用以保留的 iframe 运行，返回桌面只隐藏页面，不重新加载、不清空存档。QQ 在后台继续回复，右下角提示显示在外层桌面，在相册、搜索、空间和 AES 页面也能看到。
- QQ 记录、未读状态、相册剧情保存在当前站点的 localStorage；待回复和下一组选项也随存档保存。

## 发布时关闭刷新重置

目前保留开发行为：刷新整个桌面后重置游戏进度，以便重新测试剧情。打开 `script/game-config.js`，将：

```js
window.GAME_CONFIG = Object.freeze({ RESET_ON_REFRESH: true });
```

改为：

```js
window.GAME_CONFIG = Object.freeze({ RESET_ON_REFRESH: false });
```

这是唯一的刷新重置开关，不需要再修改 QQ.js 或 photofolder.js。发布后刷新或重新打开同一站点会保留存档。换浏览器、清除网站数据或更换域名/端口不会沿用原站点存档。

## 扩充文件夹

文件配置的 `name` 保存完整文件名（含后缀），每个文件必须有独立 `id`。普通文件夹默认隐藏后缀，可勾选「显示文件扩展名」；类型在名称下方显示。QQ 导入窗口始终显示完整文件名。地图实际为 JPEG，相册图片为 PNG。

QQ 左下角提供空间、邮箱（暂不可用）和工具。通过「工具 → 导入消息记录 → 从指定文件导入 → 浏览」打开游戏内文件选择器，与 `script/folders.js` 共用目录。备份初始为「备份/deer_cache.dat」，必须先在文件夹右键重命名为任意 `.db` 名称才能导入；导入成功显示读条和「导入成功」。数据库始终无法预览；其他文件即使改成 `.db` 也不能导入。

所有文件（包含相册）支持右键「重命名」。弹窗编辑包含后缀的完整文件名，下方类型随新后缀变化。支持的常见后缀见 `GameFiles` 的 `commonExtensions`；不支持或没有后缀时自动使用 `.txt`，同时标记格式错误，点击显示「文件格式错误，无法预览」。修改为受支持后缀可清除该标记。图片改为不匹配的后缀后显示「无法预览」，恢复原图片后缀可重新预览。修改文件名不改变文件的实际内容或身份。

文件名与格式状态保存在 `gameFileState`，扩展名设置保存在 `gameFileSettings`；文件夹与 QQ 导入窗口实时同步，刷新保留，清空游戏进度会一起重置。

备份在 `chatdata/qq-backup-001.json` 中使用游戏内部 JSON 格式，恢复联系人「林中鹿」在 `2026/06/30` 的完整历史，内容来自 `chatscript/deer.docx`，共 27 条记录（含好友添加提示）；图片删除和表情包按原稿保留文字提示。历史仅在导入这份备份后可见。联系人初始聊天为空，头像预留 `figure/avatar/deer.png`。玩家先发送「你好」，随后显示灰色内心 OS 提示（不作为聊天消息发送），再可发送「不好意思忘记改备注了，请问你是谁？」；两次发送均不触发回复，日期 `2026/07/06` 仅显示一次。恢复后增加「222」选项，发送后对方回复「你回来了吗？」，之后对话结束。已有三次问候存档会转换为新的对话顺序，保留恢复记录和口令回复进度。

修改备份中的 `conversations` 可替换恢复剧情。导入按会话及消息 ID 去重，保留现有消息、未读状态、对话选项和待回复进度；重复导入不会增加相同消息；曾导入旧测试备份的存档，再次导入时会将历史中的 `111 / 222` 占位内容替换为正式原稿。选项的 `maxSends` 限制发送次数，`requiresHistoryMessageId` 让选项只在对应历史消息恢复后出现。导入结果随 `gameChatSave` 保存，沿用现有重置机制。

在 `script/folders.js` 修改文件夹名称或增加文件夹。可添加 `{ id: "unique-image-id", name: "图片.png", src: "figure/图片.png" }` 形式的图片项；photofolder 继续使用原有相册剧情和存档。

## 图片占位

新增桌面图片使用暂不存在的 PNG 路径，上传对应文件后自动替换临时图标和渐变背景：

- `figure/desktop-wallpaper.png`：桌面壁纸
- `figure/desktop-qq.png`：QQ 图标
- `figure/desktop-photofolder.png`：相册图标
- `figure/desktop-search.png`：搜索图标

原有剧情照片与锁屏图片继续使用现有文件。QQ 头像原本引用的 `avatar/*.png` 尚未提供，可按原路径补充。

多份 QQ 备份使用独立的文件配置。第一份初始伪装为 `deer_cache.dat`；后续每份配置使用不同的 `id`（例如 `qq-message-backup-002`）和 `dataSrc`（例如 `chatdata/qq-backup-002.json`），分别存放需要恢复的消息。导入按所选文件的 `dataSrc` 读取，消息 ID 相同的记录不会重复添加。

游戏参考传统 Windows QQ 的本地数据库 `Msg3.0.db`，但允许玩家使用任意 `.db` 名称。内部仍为游戏 JSON 数据，由模拟导入流程读取。
